The context

A problem worth solving.

Sales information lived inside the company’s desktop business system, as reports someone had to run and export by hand. The team wanted the full history in one place and a safe way to ask questions without losing the original numbers.

My contribution

What I brought to the work.

Built the export agent and its verification, the storage and alerting on the company’s own AWS account, the dashboard and the read-only ChatGPT connection. An AI agent with its own cloud computer is set to sign in to the business system each morning and export the previous day’s report, so no one’s computer has to be on; every file is checked against the report’s printed totals before it is kept. The first supervised cloud run passed every check, and unattended runs are being confirmed.

The product

What it makes possible.

Five parts follow: the dashboard, the report rows behind each figure, the daily export and its checks, the ChatGPT connection, and who gets in. Each screen is a local run of the product’s own code with invented bookings; the company’s real figures stay private.

01

No one’s computer required

A hosted AI agent with its own cloud computer is scheduled to sign in to the business system each morning and export the previous day’s Booking Report as Excel. The first supervised run passed every check; unattended runs are being proven.

02

Every line checked

A report is kept only when its lines add up to the report’s own printed totals to the cent. The full history back to January 2009 was verified the same way.

03

The company’s own cloud

Storage sits in Create Spaces’ own AWS account, blocked from public access, with health alarms, a spending alert and an activity log.

04

Ask in your own ChatGPT

Each person connects their own ChatGPT through a read-only connection, switched on in October 2026. The connection returns every figure with the report row it came from and has no way to change the data.

05

See the business

A dashboard opens on the latest day, then bookings, gross profit and margin by salesperson for the latest day, the last 7 days, the month so far or all saved history, the original Excel rows, and a calendar of every day received.

The dashboard

Yesterday’s bookings, then any period, without opening a report.

The dashboard opens on the latest report day in one paragraph of figures, then shows bookings, gross profit, margin and orders for the latest day, the last seven days, the month so far or everything saved, ranked by salesperson.

Sources

Every figure opens the Excel row it came from.

Nothing on the dashboard is a number on its own. A figure links to its line in the saved report, shown exactly as it was exported, and the original workbook can be downloaded.

Collection

An agent collects the report; every file is checked before it is kept.

First supervised run passed every check · the daily schedule is being proven run by run

An AI agent with its own cloud computer is set to open the business system each morning and export the previous day’s report. The Exports page shows what is collected, when it last arrived and when the next one is due, and each file is kept only if its lines add up to the report’s own printed totals.

The ChatGPT connection

Each person asks in their own ChatGPT; the connection can only read.

The connection gives ChatGPT a small set of read-only tools over the saved reports. Every answer carries the report, sheet and row behind each figure, and a request without a valid company sign-in is refused before any data is read.

Access and operation

Private to the company, with the controls kept for the operator.

The reports sit behind a company sign-in that admits only invited addresses. The schedule, the monthly budget and the pause switch are shown to the service operator alone.

Engineering choices

The decisions behind the interface.

01

Verify before keeping.

A new report replaces nothing until its rows reconcile with the report’s printed totals. A failure keeps the last good data in place and raises an alert.

02

Point every answer at its row.

The ChatGPT connection is read-only and returns the Excel row behind each figure, so an answer can be checked against the source.

More than 1,200 automated tests cover the export, verification, dashboard and connection. The dashboard and the ChatGPT connection went live on 1 October 2026; the daily schedule is the remaining rollout step.

Where it stands

Live, and still rolling out.

The verified history, the dashboard and the ChatGPT connection are live on the company’s own AWS account, behind a company sign-in. The daily schedule is being proven run by run.
