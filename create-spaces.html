The context

A problem worth solving.

Useful sales data lives inside business software. Before a conversational dashboard can be dependable, exports must land somewhere the analysis workflow can actually read.

My contribution

What I brought to the work.

Developed the Hedberg bookings-report workflow and a local reporting dashboard connected to private cloud storage. The workspace brings PDF-derived data, saved reports and export status into one interface, while keeping the future conversational layer separate.

The product

What it makes possible.

01Review bookings+

The overview presents accepted booking data alongside report coverage and freshness. Figures can be traced back to the source report.

02Keep report history+

Saved report versions retain their date ranges and source PDF links. Repeated exports remain distinct from newly covered reporting periods.

03Inspect the export workflow+

The dashboard displays the cloud export schedule, pause control, expandable run history and read-only Booking Report configuration.

04Build toward conversation+

A conversational AI workspace, editable export frequency and Sync now remain planned.
